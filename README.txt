E-COMMERCE REVENUE PERFORMANCE ANALYSIS
Author: Rupeli Pradhan (MBA Candidate, 2026-2028)

PROJECT OVERVIEW:
This project analyzes 1,000 retail transaction records using Microsoft Excel to identify structural drops in revenue and propose digital marketing solutions.

KEY DATA FINDINGS:
- Using Excel Pivot Tables, I isolated revenue by category.
- The "Books" segment was identified as the lowest-performing category, generating only 29,889.04 in total revenue.
- This stands in stark contrast to high-performing categories like Electronics, which generated over 6.9 Million.

STRATEGIC MBA RECOMMENDATION:
1. Google Ads Search: Launch targeted keyword ads for terms like "buy textbooks online" to capture high-intent buyers for the Books category.
2. Google Ads Display: Build a remarketing framework to re-engage website drop-off visitors.
3. Google Analytics 4 (GA4): Set up purchase event tracking tags to monitor drop-off paths and improve conversion rates.
